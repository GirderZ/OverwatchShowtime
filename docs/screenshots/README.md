## 更新截图

在源码目录执行 `npm run preview`，打开其输出的本地预览地址并保留 `?demo=1` 参数。依次查看浅色与深色仪表盘、游玩记录和周报月报，保存页面截图。首页保留“演示”标识；记录和报表可以切换日期，但应始终使用虚构数据。

截图只用于文档展示，不随 Windows 应用打包。界面有变化时请一并更新图片和根目录 README 中的说明。
